# 简历编辑器

一个纯前端的单页项目，直接打开 [index.html](D:\code\新建文件夹\index.html) 就能使用。

## 功能

- 编辑基础信息
- 新增、删除、上移、下移自定义模块
- 给每个模块新增或删除字段
- 给每个模块新增多条内容
- 右侧实时预览简历
- 自动保存到浏览器 `localStorage`
- 导入 / 导出 JSON
- 打印或导出 PDF

## 文件

- [index.html](D:\code\新建文件夹\index.html): 页面结构
- [styles.css](D:\code\新建文件夹\styles.css): 页面样式
- [app.js](D:\code\新建文件夹\app.js): 状态管理和交互逻辑

## 使用方式

1. 直接用浏览器打开 [index.html](D:\code\新建文件夹\index.html)。
2. 在左侧编辑基础信息和自定义模块。
3. 通过“新增模块”和“新增字段”自由组织简历结构。
4. 点击“导出 JSON”备份数据，点击“导入 JSON”恢复数据。
5. 点击“打印 / 导出 PDF”生成可投递版本。
